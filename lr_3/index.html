Лабораторная работа №3. REST API библиотеки¶

Студент — Чуприн Сергей, группа K3339. Учебный год — 2026–2027.

Цель работы¶

Разработать серверную часть приложения с помощью Django REST Framework, описать модель данных средствами Django ORM, подключить авторизацию по токенам через Djoser и документировать API.

Предметная область¶

Система предназначена для сотрудника библиотеки. Сотрудник ведёт каталог, записывает читателей в библиотеку, закрепляет их и экземпляры книг за читальными залами, оформляет выдачу и возврат книг. История закреплений позволяет сформировать месячный отчёт по залам.

Через API можно получить список книг на руках у читателя, найти читателей с просроченными выдачами и выдачами редких книг, посчитать читателей младше 20 лет и посмотреть статистику образования.

Стек¶

Python 3.12, Django, Django REST Framework, PostgreSQL, Psycopg, Djoser и MkDocs.
