# Лабораторная работа №1. Работа с сокетами

## Цель работы

Понять принципы межсокетного взаимодействия в вебе. Научиться реализовывать базовую
архитектуру клиент-сервер.

Все задания выполнены на стандартных модулях `socket` и `threading`. Клиент чата
из задания 4 дополнительно использует библиотеку `colorama` для цветного вывода.

## Задания

| № | Тема | Протокол | Файлы |
|---|------|----------|-------|
| 1 | [Обмен сообщениями «Hello»](task1.md) | UDP | `task1/server.py`, `task1/client.py` |
| 2 | [Вычисления через TCP (вариант 1 — теорема Пифагора)](task2.md) | TCP | `task2/server.py`, `task2/client.py` |
| 3 | [Раздача HTML-страницы по HTTP](task3.md) | TCP / HTTP | `task3/server.py`, `task3/client.py`, `task3/index.html` |
| 4 | [Многопользовательский чат](task4.md) | TCP + потоки | `task4/server.py`, `task4/client.py` |
| 5 | [Простой веб-сервер (GET/POST)](task5.md) | TCP / HTTP | `task5/server.py`, `task5/client.py` |

## Оценивание

- 60% — выполнение заданий 1–4 и однопользовательского чата (без потоков).
- 100% — выполнение заданий 1–5 и многопользовательского чата (с потоками).

В работе выполнены задания 1–5 и многопользовательский чат на TCP с потоками.
